# Contratos externos

Esta pasta contém contratos de integração versionados, sem implementar os
serviços externos correspondentes.

- `heal_plus/`: mensagens e referências aceitas na fronteira do Heal+.

Contratos não autorizam transmissão de dados. Qualquer integração real exige
autenticação, autorização, consentimento, minimização, criptografia, auditoria
sem payload clínico e aprovação institucional.
